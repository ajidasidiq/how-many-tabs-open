347 — one honest number: the count of open browser tabs. Far above the dozen most people keep open, yet a real hoarder's count, odd and unrounded so it reads as counted, not guessed. `main.py` writes exactly those three digits to `/output/entry.txt` and reads them back to confirm nothing extra slipped in.

## Run it

```sh
python3 main.py
```

`main.py` writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT`), then reads it back and refuses to finish unless the file holds exactly the digits it meant to send.
